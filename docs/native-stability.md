# 原生连接稳定性

SDK 按 PID 独占进程，同一微信只允许一个受控会话。已禁用的历史裸挂载探针不能与机器人并行使用。SDK 和机器人均不会自动启动或重启微信。

关闭会话首先禁止新 RPC，再等待已进入的原生调用和发送事务完成。资源、数据库和主脚本依次确认清理成功后才能卸载、断开和释放独占锁。任一阶段失败时保留连接及锁，并记录 cleanup_errors；调用者可以稍后再次 close。禁止在 cleanup_errors 后自行卸载脚本或强制再次注入。待清理会话由 SDK 保留引用，防止垃圾回收提前断开。

配置监听对象时使用 NativeWeChatAdapter.reconfigure_targets：先完成全部身份解析，验证通过后替换映射。失败保留旧配置，不重新挂载，不改变微信进程。

2026-11-15 的回归包含并发 RPC 与关闭、清理失败隔离及重试、资源子脚本失败保留父会话、监听对象更新不重新连接。实机短时验证通过不等于所有注入运行时崩溃均已定位；崩溃记录仍需按实际进程及时间分析。

桌面退出也检查待清理会话。若仍未静止，保留菜单栏和窗口并暂缓退出，允许稍后重试；不会通过退出 Python 进程间接强制卸载尚在运行的回调。
